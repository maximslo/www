This first block is a normal paragraph. You write plain text and it
becomes a `<p>`. You can mark words as **bold** or *italic*, and drop in
`inline code` mid-sentence.

## A second-level heading

Headings use `##`. Below it, here's a paragraph with a [link to the
homepage](/) — links get underlined in ink.

A plain Markdown image (full-width):

![A single full-width image](/images/project-three.jpg)

A single full-width, optimized image (`cols={1}`):

<Grid cols={1} images={[
  { src: "demo/one.jpg", alt: "A single full-width image" },
]} />

A single image scaled to one cell of a 2-column grid (left-aligned, half width):

<Grid cols={2} images={[
  { src: "demo/one.jpg", alt: "A single half-width image" },
]} />

A two-column grid of optimized images:

<Grid cols={2} images={[
  { src: "demo/one.jpg", alt: "First screen" },
  { src: "demo/two.jpg", alt: "Second screen", caption: "Captions are optional" },
]} />

A three-column grid:

<Grid cols={3} images={[
  { src: "demo/one.jpg", alt: "One" },
  { src: "demo/two.jpg", alt: "Two" },
  { src: "demo/three.jpg", alt: "Three" },
  { src: "demo/four.jpg", alt: "Four" },
]} />
