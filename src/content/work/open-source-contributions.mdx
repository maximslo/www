I first heard of Astro in 2023 at The Washington Post. It's a web framework that ships zero-JS by default. Famous for it's interactive "islands" architecture as a response to how most of the static web is overengineered with React.

Started contributing. Now we're releasing Flue.

Flue is an *Agent Harness* framework. Open source just like Astro.

It was originally built to automate AI workflows inside Astro's own GitHub repositories (issue/PR triage, validation, etc.), so it literally grew out of the project's internal needs.

Complete runtime with first-class concepts, strong conventions, and minimal boilerplate.

https://flueframework.com/
