Flue is an *Agent Harness* framework for building agents.

It was originally built to automate AI workflows inside Astro's own GitHub repositories, so it literally grew out of the Astro project's internal needs.

Ships a complete runtime with first-class concepts, strong conventions, and minimal boilerplate.
